Job Searching Portal 💼
A modern job-searching portal built with React, HTML and Tailwind CSS. The app uses React Router for navigation and integrates with a public API endpoint for job listings and details.

🛠️ Features
Search and filter jobs based on various criteria.
Detailed job descriptions and application links.
Responsive and user-friendly design with Tailwind CSS.
Seamless navigation using React Router.
🚀 Tech Stack
Frontend
Framework: React
Styling: Tailwind CSS, HTML
Routing: React Router
Backend
Data Source: Public API endpoint for job listings

📦 Installation & Setup

Install dependencies:
npm install  

Start the development server:
npm run dev  

🔗 Public API Integration
The application fetches job-related data from a public API endpoint to display the latest job listings.

💼 Job Portal Features
Search for jobs using keywords and filters.
View detailed job descriptions and requirements.
Navigate seamlessly between pages for a smooth experience.
